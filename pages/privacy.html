1. בקצרה

המערכת עוזרת למורה ללוות תלמידים בעבודת גמר: מועדים, משימות, הגשת קבצים, הערות ומשוב. כל הנתונים נשמרים בחשבון Google של המורה שהקים את המערכת, ולא אצל מפעיל האתר. מפעיל האתר אינו רואה, אינו מקבל ואינו שומר שמות תלמידים, עבודות, הערות או ציונים.

2. איך המערכת בנויה

  • האתר הוא קבצים סטטיים (דפדפן בלבד) המוגשים מ-GitHub Pages. אין בו מסד נתונים של מפעיל האתר.
  • שרת המורה: כל מורה מקבל עותק של קוד המערכת בחשבון Google שלו (Google Apps Script). השרת רץ בחשבון המורה ובשמו.
  • האחסון: הנתונים נשמרים בתיקיות Google Drive של המורה ובמאפייני הסקריפט שבחשבונו.
  • עדכונים: שרת המורה בודק מעת לעת באתר הציבורי אם קיימת גרסה חדשה, מוודא שהיא חתומה דיגיטלית על ידי מפעיל האתר, ומתקין אותה. בבדיקה זו לא נשלח לאתר שום מידע אישי או נתוני תלמידים.

לכן המורה הוא בעל המידע ובעל השליטה בו, כמו בכל מסמך שהוא שומר ב-Drive שלו.

5. מי יכול לגשת למידע

  • המורה לכל נתוני המערכת שלו. התלמיד רק לנתונים שלו ולמה שהמורה בחר להציג לו. תלמידים אינם רואים נתונים אישיים של תלמידים אחרים.
  • מפעיל האתר: אין גישה לנתוני מורים ותלמידים. הוא מפרסם גרסאות חתומות של הקוד בלבד.
  • Google מספקת את תשתית האחסון וההרצה לפי מדיניות הפרטיות והתנאים שלה, החלים על חשבון המורה. GitHub מארחת את קבצי האתר הסטטיים ומקבלת, כמו כל אתר, כתובות IP ופרטי דפדפן בעת טעינת האתר, לפי מדיניותה.

6. תלמידים קטינים

  1. הכללת תלמיד במערכת נעשית על ידי המורה במסגרת תפקידו החינוכי.
  2. באחריות המורה לוודא שיש לו הסמכות וההרשאות הנדרשות מבית הספר ו/או מהורי התלמידים להשתמש בכלי ובאחסון Google, בהתאם לנהלי בית הספר, להנחיות משרד החינוך ולחוק הגנת הפרטיות.
  3. מומלץ ליידע הורים ותלמידים מראש שנעשה שימוש במערכת, מה נשמר ואצל מי.
  4. מפעיל האתר אינו פונה לתלמידים ואינו יוצר איתם קשר.

7. אבטחת מידע

  • הנתונים נשמרים בתשתית Google ומוגנים באבטחת חשבון Google של המורה. מומלץ מאוד להפעיל אימות דו-שלבי.
  • עדכון מותקן רק אם הוא חתום דיגיטלית (Ed25519) על ידי מפעיל האתר ועובר בדיקת שלמות. עדכון לא חתום או ששונה נדחה.
  • אם גרסה חדשה אינה פועלת, השרת חוזר אוטומטית לגרסה הקודמת, בלי פגיעה בנתונים.
  • לפני כניסת תלמיד, האתר מאמת מול Google ומציג לתלמיד את חשבון Google של בעל השרת, כדי להגן מפני שרת מתחזה.
  • אין מערכת חסינה לחלוטין. באחריות המורה לא לשתף קישורי גישה ולא להעניק לאחרים גישה לחשבונו.
  • אם יתגלה פגם שעלול לחשוף מידע, יופץ עדכון מתקן ותפורסם הודעה באתר.

  • המורה שולט בנתונים: אפשר לערוך, לייצא (גיבוי) ולמחוק אותם.

  • בקשת תלמיד או הורה לעיין, לתקן או למחוק מידע מופנית למורה, בעל המידע.

Privacy Policy (English summary)

Student-and-teacher project guidance system for Israeli high-school thesis projects. Operator: אורי העליון. Contact: uribyology@gmail.com. Last updated: 2026-11-02.

What the app does. The site is a static web app. Each teacher sets up their own private copy of the server code in their own Google account (Google Apps Script). All data (students, tasks, submissions, feedback, grades) is stored only in that teacher's Google Drive. The operator has no database and cannot access teacher or student data.

Google user data. Sign-in uses basic profile identifiers (openid, email, name) to match users to the teacher's roster. During the one-time teacher setup, the setup page (running in the teacher's browser) uses the Apps Script API and Cloud Resource Manager/Service Usage APIs, with the teacher's explicit consent, solely to create and deploy the teacher's own Apps Script project and personal Cloud project. Those access tokens stay in browser memory, are not stored, and are not sent to the operator or any third party. The teacher's own server later asks the teacher for Drive access to store its data in the teacher's own Drive, and for permission to install signed updates.

Limited Use. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide user-facing features; it is not sold, not used for advertising, not shared with third parties, not used to train AI models, and not read by humans at the operator.

Retention and deletion. Data lives in the teacher's account and is controlled by the teacher. Deleting the Drive folder and the Apps Script and Cloud projects removes everything. Access can be revoked at myaccount.google.com/permissions.
